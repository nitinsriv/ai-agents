# Prompt-to-Code AI Agent CLI

This script provides a simple command-line interface for generating code snippets using an AI agent. The user specifies a programming language and a problem description, and the agent generates a solution code snippet, extracting and saving the relevant code (in Java, by default) to an output file.

## Features

- **Interactive User Prompt**: Ask the user for the desired programming language and problem for code generation.
- **AI Agent Integration**: Utilizes LangChain's OpenAI-powered agent to generate code snippets.
- **Code Extraction**: Searches the AI output for code enclosed in markdown code blocks.
- **Automatic Code Saving**: Extracts the code (default: Java) and writes it to `output.txt`.

## Dependencies

- [LangChain OpenAI](https://python.langchain.com/docs/integrations/openai)
- [python-dotenv](https://pypi.org/project/python-dotenv/)
- Your own `Agent` implementation in `browser_use.py`
- Python 3.8+
- OpenAI API Key (set in a `.env` file)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/nitinsriv/ai-agents.git
cd ai-agents
```

### 2. Install Dependencies

```bash
pip install langchain-openai python-dotenv
```

> You may need to install additional dependencies if required by your custom `Agent`.

### 3. Set up OpenAI API Key

Create a `.env` file in the project directory with your OpenAI API key:
```
OPENAI_API_KEY=your_openai_api_key_here
```

### 4. Run the Script

```bash
python play_webUI.py
```

Follow the prompt and specify:
- The programming language (e.g., "Java")
- A description of the problem you want solved

### 5. Output

- The generated solution will be displayed.
- The extracted code snippet will be saved in `output.txt`.

## Example Usage

```text
Specify the programming language and the problem for which the code snippet has to be generated by the agent AI: Java - implement binary search on a sorted array
Final Result: ... (Full AI response with the code block)
Java Code:
public class BinarySearch {
    ...
}
```

## Notes

- The script currently extracts code blocks assuming they are in markdown format and labeled with a language (e.g., ```java).
- If the language or formatting changes, you may need to modify the regular expression in the script to match your use case.
- Only the first matching code block from the AI response is extracted and saved.
- For best results, ensure your `Agent` class is compatible with this flow.
